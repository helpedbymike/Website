Drop the eight path artworks in this folder to replace the generated ones:

  family.png  discipline.png  purpose.png  faith.png
  freedom.png passion.png     growth.png   legacy.png

Square images, centred composition, black background — the black is keyed out
before printing so the same file works on the Bone colourway as well as Onyx.
Around 1024x1024 is plenty.

Nothing here is required. When a file is missing the site draws its own emblem
for that path (see js/art.js), so the page never breaks — you will just see
eight 404s in the console, which is the site checking whether you added them.

Run ../../tools/fetch-designs.sh to pull them down automatically.
